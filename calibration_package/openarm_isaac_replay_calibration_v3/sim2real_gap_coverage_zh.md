# OpenArm 完整 Sim2Real Gap 覆盖表

当前 v3 只覆盖“关节位置响应的 compare/replay”。以下各层必须独立采集、拟合、验证，不能用关节 offset 代替。

| 类别 | 典型差异 | Isaac 中应做的事 | 真机如何验证 |
|---|---|---|---|
| 坐标系与运动学 | 基座位姿、TCP、URDF 轴方向、左右臂镜像、相机外参不一致 | 校准 base/TCP/frame transform；检查 joint axis、符号与限位 | 多姿态末端位姿、标定板或外部视觉比较 |
| 速度与加速度 | 真机限速、加速度、jerk、控制器插补不同 | 匹配控制频率、轨迹插补、速度/加速度/jerk 限制 | 阶跃与斜坡响应、峰值速度、到达时间 |
| 力与接触 | 摩擦、质量、质心、接触刚度、阻尼、反弹不同 | 随机化物体质量、摩擦、COM、restitution；调接触求解器 | 推、抓、放、碰撞任务的力、位移与成功率 |
| 执行器饱和 | 扭矩、速度、温度、电压使真实系统无法达到指令 | 设置真实 drive 力矩、速度和饱和；禁止无限刚度假设 | 大负载、不同姿态下的跟踪误差与失败率 |
| 负载与重力 | 姿态变化后重力矩和线缆拖拽改变误差 | 使用准确 link 质量、惯量、COM；随机化 payload | 不同姿态、空载/抓取后重复同一轨迹 |
| 观测噪声 | 编码器量化、相机噪声、深度缺失、曝光变化 | 注入编码器/相机噪声、模糊、曝光和深度空洞 | 静止标准差；不同光照和背景下的视觉稳定性 |
| 相机模型 | 内参、畸变、外参、时间同步、遮挡不同 | 使用实际内参与畸变；随机化相机位姿和照明 | 重投影误差、物体位姿误差、手眼标定残差 |
| 感知到控制延迟 | 相机帧、推理、ROS、控制链路时间不同 | observation/action buffer、丢帧、抖动与匹配控制率 | 图像时间戳、推理时间、命令到反馈 delay |
| 初始状态分布 | 真机初始姿态、物体位置、夹爪状态不如仿真理想 | 随机化初始关节、物体位姿、抓取预状态 | 多次重新放置物体和不同初始姿态 |
| 任务环境 | 桌面摩擦、物体材质、柔性、线缆、遮挡 | 真实材质参数范围随机化；加入干扰物 | 跨对象、跨桌面、跨光照、跨摆放验证 |
| 夹爪与抓取 | 开口、力、摩擦、柔顺性、接触几何不同 | 建模夹爪限位、速度、接触摩擦和物体尺寸误差 | 抓取成功率、滑落率、夹爪位置与物体相对位姿 |
| 系统可靠性 | DDS 丢包、节点重启、重复发布者、状态陈旧 | watchdog、唯一命令源、时间戳门、故障停止 | 长时间运行、网络扰动、重启恢复测试 |
| 安全约束 | 仿真没有碰撞、工作区、急停等真实约束 | 关节/速度/工作区/自碰撞限制与 safety supervisor | 独立验证每条限制和停止逻辑 |

## 分层执行顺序

1. **基础动作层**：关节 name/unit/sign、drive、限位、位置、速度、delay、饱和。
2. **几何和观测层**：base/TCP、相机、手眼、坐标系、观测噪声与同步。
3. **物理交互层**：质量、惯量、摩擦、接触、夹爪、payload、桌面和物体。
4. **系统与安全层**：网络、watchdog、恢复、唯一命令源、工作区与急停。
5. **任务层**：多初始状态、多对象、多环境下比较 nominal、随机化和残差策略。

每层都要有独立配置版本、数据集、有效域、真机验证指标和失败停止条件。上层失败不能回写为下层的固定 joint offset。
