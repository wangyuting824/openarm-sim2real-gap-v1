# OpenArm 夹爪运动学标定协议 v1

## 目标

为左右夹爪分别建立并验证连续命令关节值 `q`（rad）到实际两指开口宽度 `w`（m）的关系。它只覆盖空载开口、回程、限位和 Isaac 映射；不把 `effort` 当作夹持力，也不覆盖物体接触或抓取成功率。

## 已知接口

- 真机：每侧一个受控关节：`openarm_left/right_finger_joint1`；ROS 控制器为 position interface。
- Isaac：每侧两个 finger DOF；`finger_joint2` 是 `finger_joint1` 的 mimic，因此一个主关节命令决定一对手指。
- 接口接受连续浮点 position target。因此“开”“半开”“闭”是同一个连续区间内的不同目标，不是三个离散模式。
- 现有硬件代码把 `pinch_gripper` 的关节值直接映射到电机弧度，并标注 true mapping 尚未完成；不能将此当作已经验证的开口宽度模型。

## 执行顺序

1. **只读审计**：保存控制器、URDF mimic、关节限位和硬件映射的版本/hash。
2. **真机空载开口扫描**：机械臂保持归位且不运动；每侧单独执行已授权的从当前安全开度到安全闭合、25%、50%、75%、安全张开，再按反向返回的有限轨迹。每个点稳定后量实际开口宽度，记录 command、反馈、宽度和照片/量具读数。
3. **拟合与留出验证**：对每侧、正向和反向分别拟合 `q → w`；至少留出一个中间开度。报告 MAE、最大误差、回程差和安全开度范围。
4. **Isaac-only**：用相同主关节 target 验证两 finger DOF 的 mimic、限位和定义的开口宽度，不能以视觉外观替代数值记录。
5. **发布**：仅在真机和 Isaac 的开口定义一致、留出误差满足已声明任务容差时写入版本化 gripper override。无接触的标定包不得宣称夹持力或抓取可靠性。

## 物理试验门槛

实际夹爪运动需要具名单次授权，且授权必须写明左右哪一侧、关节目标范围、点数、每点保持时间、总时长、回到的安全开度、急停/现场清场/绿灯确认和唯一命令发布者。开始前机械臂回零并保持；试验只动一个夹爪。若量具、开口定义或反馈缺失，停止而不拟合。

## 通过定义

通过不是“夹爪会开合”。每侧必须同时满足：

1. command 和反馈在声明的安全范围内稳定；
2. 中间点的实测开口连续且单调；
3. 正反向回程差已量化；
4. 留出点的 `q → w` 误差不超过任务声明的开口容差；
5. Isaac 的主/从 finger 关系和开口定义与真机标定包一致。

任务容差尚未定义时，结果只能标为 `gripper_kinematic_candidate`。
